# Editor overview

The SQL editor is built on [CodeMirror 6](https://codemirror.net/). It is a full-featured code editor configured specifically for SQL authoring against a live database schema.

![SQL editor with autocomplete active](/docs/screenshots/editor-overview.png)

## Core editing features

- **Syntax highlighting** — SQL keywords, identifiers, strings, and comments each have distinct colors using a custom dbpeek dark theme
- **Bracket matching** — matching parentheses are highlighted when the cursor is adjacent to one
- **Line numbers** — shown in the gutter; click a line number to select the entire line
- **Smart indentation** — pressing Enter inside a parenthesized expression indents the new line automatically
- **Multi-cursor** — hold <Kbd>⌥</Kbd> and click to place additional cursors; edits apply to all cursors simultaneously
- **Rectangular selection** — hold <Kbd>⌥</Kbd> and drag to select a column of text across multiple lines

## Toolbar

The toolbar sits above the editor and contains:

| Button | Action | Shortcut |
|--------|--------|----------|
| **Run** | Execute the current query | <Kbd>⌘</Kbd><Kbd>↵</Kbd> |
| **Format** | Format and uppercase keywords | <Kbd>⌘</Kbd><Kbd>⇧</Kbd><Kbd>F</Kbd> |
| **Cancel** | Abort the running query | <Kbd>⌘</Kbd><Kbd>.</Kbd> |
| **EXPLAIN** | Run EXPLAIN ANALYZE on current query | <Kbd>⌘</Kbd><Kbd>E</Kbd> |

The Cancel button only appears while a query is executing. It is not shown at rest.

## Tab bar

Above the toolbar is the tab bar. Each tab is an independent workspace with its own:

- SQL text
- Query results and result view mode (grid / chart / explain)
- Client-side sort and filter state
- Query history

See [Multi-tab queries →](/editor/multi-tab) for full tab management details.

## Keyboard reference

| Action | Mac | Windows/Linux |
|--------|-----|---------------|
| Run query | <Kbd>⌘</Kbd><Kbd>↵</Kbd> | <Kbd>Ctrl</Kbd><Kbd>↵</Kbd> |
| Format SQL | <Kbd>⌘</Kbd><Kbd>⇧</Kbd><Kbd>F</Kbd> | <Kbd>Ctrl</Kbd><Kbd>⇧</Kbd><Kbd>F</Kbd> |

| EXPLAIN | <Kbd>⌘</Kbd><Kbd>E</Kbd> | <Kbd>Ctrl</Kbd><Kbd>E</Kbd> |
